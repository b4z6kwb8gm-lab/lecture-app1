大問[1] ガウス型波束と最小不確定性原理（解説ノート）

ガウス積分を用いた規格化条件、平方完成による \(u(x)\) の導出、不確定性の積 \(\Delta x \Delta p\)。

大問1 (a)重み関数 \(\hat{u}(k)\) の規格化定数 \(A\)

【詳細ステップ】 規格化条件 \(\int_{-\infty}^{\infty} |\hat{u}(k)|^2 dk = 1\) に \(\hat{u}(k) = A \exp\left[ -\frac{(k - k_0)^2}{2\sigma^2} \right]\) を代入する：

\[ |A|^2 \int_{-\infty}^{\infty} \exp\left[ -\frac{(k - k_0)^2}{\sigma^2} \right] dk = 1 \]

ガウス積分の公式 \(\int_{-\infty}^{\infty} e^{-a(k-k_0)^2} dk = \sqrt{\frac{\pi}{a}}\) （\(a = \frac{1}{\sigma^2}\)）を適用する：

\[ \mathbf{A = \frac{1}{\pi^{1/4}\sqrt{\sigma}}} \]

大問1 (b)逆フーリエ変換と位置の確率密度 \(|u(x)|^2\)

【詳細ステップ】 定義 \(u(x) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{\infty} \hat{u}(k) e^{ikx} dk\) に代入し、指数部分を \(k\) について平方完成する：

\[ -\frac{(k - k_0)^2}{2\sigma^2} + ikx = -\frac{1}{2\sigma^2}\left( k - k_0 - i\sigma^2 x \right)^2 - \frac{\sigma^2 x^2}{2} + i k_0 x \]

\(k\) に関するガウス積分を実行すると \(\sqrt{2\pi \sigma^2} = \sqrt{2\pi}\sigma\) が現れ、前線の分母 \(\sqrt{2\pi}\) と相殺する：

\[ \mathbf{|u(x)|^2 = A^2 \sigma^2 e^{-\sigma^2 x^2} = \frac{\sigma}{\sqrt{\pi}} e^{-\sigma^2 x^2}} \quad (\text{\(x=0\) を中心とするガウス分布}) \]

大問1 (c)標準偏差 \(\Delta x, \Delta p\) と最小不確定性

分布より \(\Delta x = \frac{1}{\sqrt{2}\sigma}\)、\(\Delta p = \hbar \Delta k = \frac{\hbar \sigma}{\sqrt{2}}\) となる。

\[ \mathbf{\Delta x \Delta p = \left(\frac{1}{\sqrt{2}\sigma}\right) \left(\frac{\hbar \sigma}{\sqrt{2}}\right) = \frac{\hbar}{2}} \quad (\text{理論的最小値を達成}) \]

大問[2] 1次元ポテンシャル段差と反射・透過（解説ノート）

段差ポテンシャル \(V_0 < E\) に対するシュレディンガー方程式、確率流束 \(j\)、反射率 \(R\)・透過率 \(T\)。

大問2 (a)(b)(c)解の設定と接続条件

領域1 (\(x<0\)): \(u_1 = A_1 e^{i k_1 x} + A_2 e^{-i k_1 x}\) \(\left(k_1 = \frac{\sqrt{2m_e E}}{\hbar}\right)\)

領域2 (\(x \ge 0\)): \(u_2 = B_1 e^{i k_2 x}\) \(\left(k_2 = \frac{\sqrt{2m_e (E-V_0)}}{\hbar}\right)\)

\(x=0\) での連続および微分連続条件を連立させて解く：

\[ \mathbf{A_2 = \frac{k_1 - k_2}{k_1 + k_2} A_1}, \qquad \mathbf{B_1 = \frac{2k_1}{k_1 + k_2} A_1} \]

大問2 (d)反射率 \(R\) と透過率 \(T\)

流束密度比より：

\[ \mathbf{R = \left|\frac{A_2}{A_1}\right|^2 = \left(\frac{k_1 - k_2}{k_1 + k_2}\right)^2}, \qquad \mathbf{T = \frac{k_2}{k_1}\left|\frac{B_1}{A_1}\right|^2 = \frac{4 k_1 k_2}{(k_1 + k_2)^2}} \quad (R+T=1) \]

大問[3] 水素原子 \(p_z\) 軌道と動径極限解析（解説ノート）

球面調和関数 \(Y_{1,0}\)（\(p_z\) 軌道）の導出、プロット形状、原点極限 \(r \to 0\) のEuler型方程式。

大問3 (a)(b)\(Y_{1,0}\)（\(p_z\) 軌道）の形と概形特徴

一般公式に \(l=1, m=0\) を代入する (\(x=\cos\theta\))：

\[ \mathbf{Y_{1,0}(\theta) = \sqrt{\frac{3}{4\pi}}\cos\theta} \]

【概形の特徴】 \(\theta = 0, \pi\) （\(z\) 軸上）で最大値をとり、\(\theta = \pi/2\) （\(x-y\) 平面上）で \(0\) となる。\(z\) 軸方向に上下に伸びた2つのダンベル型ローブを描く。

大問3 (c)\(l=1\)（\(p\) 軌道）の原点極限 \(r \to 0\) 解

\(r \to 0\) では遠心力項 \(\frac{\hbar^2 \cdot 1(1+1)}{2m_e r^2}\) が支配的となり、Euler型微分方程式 \(\frac{d^2 \chi}{dr^2} - \frac{2}{r^2}\chi = 0\) を得る。試行解 \(\chi = r^s \implies s = 2, -1\)。発散防止より：

\[ \mathbf{\chi(r) \propto r^2} \qquad \left( \implies R(r) = \frac{\chi(r)}{r} \propto r^1 \right) \]

大問[4] 【最高峰融合問題】 3次元球状デルタ障壁（解説ノート）

大問2（1次元障壁散乱）× 大問3（3次元動径方程式）の融合。動径不連続条件と透過振幅。

融合問題 (a)(b)動径方程式と境界連続条件

【(a) 動径方程式】 \(l=0\) かつ \(r \neq a\) で \(V(r)=0\) のため自由粒子型同次方程式：\(\frac{d^2 \chi}{dr^2} + k^2 \chi(r) = 0\)

【(b) 連続条件】 \(r=a\) における \(\chi_1(a) = \chi_2(a)\) より：

\[ \mathbf{A \sin(ka) = B e^{-ika} + C e^{ika}} \]

融合問題 (c)微分の不連続条件（ジャンプ条件）の証明

方程式を微小区間 \([a-\epsilon, a+\epsilon]\) で積分し \(\epsilon \to 0\) の極限をとる：

\[ \mathbf{\left.\frac{d\chi_2}{dr}\right|_{r=a} - \left.\frac{d\chi_1}{dr}\right|_{r=a} = \frac{2m_e \alpha}{\hbar^2} \chi(a)} \quad (\text{証明終了}) \]

融合問題 (d)透過振幅比 \(\frac{C}{A}\) の導出

\(\beta = \frac{2m_e \alpha}{\hbar^2}\) と置く。不連続条件に代入して \(B\) を消去する：

\[ \mathbf{\frac{C}{A} = \frac{1}{2} + \frac{\beta}{2ik} e^{-ika} \sin(ka)} \]

大問[4] 演習クイズ（融合球状障壁）

問題文とヒント公式を見て正しい選択肢を選んでください。

大問[4](c)Q5\(r=a\) での微分の不連続条件

微小区間積分とデルタ関数の性質 \[ -\frac{\hbar^2}{2m_e}\int_{a-\epsilon}^{a+\epsilon} \chi'' dr + \alpha \int_{a-\epsilon}^{a+\epsilon} \delta(r-a)\chi(r) dr = 0 \]

\(r=a\) における 1階微分の跳び（不連続条件）として正しい式を選べ。

正解は **2** です。\(-\frac{\hbar^2}{2m_e}(\chi_2'(a) - \chi_1'(a)) + \alpha \chi(a) = 0\) を変形すると \(\chi_2'(a) - \chi_1'(a) = \frac{2m_e \alpha}{\hbar^2}\chi(a)\) となります。

大問[4](d)Q6透過振幅比 \(\frac{C}{A}\)

導出された解法関係 \[ \beta = \frac{2m_e \alpha}{\hbar^2}, \qquad B e^{-ika} = A \sin(ka) - C e^{ika} \]

球状障壁を抜ける透過振幅比 \(\frac{C}{A}\) の正しい形を選べ。

正解は **2** です。微分の不連続条件に \(B\) を消去して代入すると \(\frac{C}{A} = \frac{1}{2} + \frac{\beta}{2ik}e^{-ika}\sin(ka)\) と計算されます。
