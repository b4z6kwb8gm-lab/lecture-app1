[1] 波動関数と重み関数（フーリエ変換）

波数空間の重ね合わせから実空間の波動関数 \(u(x)\) を導出する問題です。

Q1(a) 全波数帯域の重み \(\hat{u}(k) = \frac{1}{\sqrt{2\pi}}\)

あらゆる波数が均一に重ね合わさっている場合の波動関数 \(u(x)\) として正しいものを選べ。

\(u(x) = \frac{1}{2\pi} \int_{-\infty}^{\infty} e^{ikx} dk\) は、ディラックのデルタ関数 \(\delta(x)\) の積分表示そのものです。位置の不確定性が0の完全局所化状態を表します。

Q2(b) 帯域制限 \(\hat{u}(k) = 1 \; (|k| \le 1)\)

波数幅が \(|k| \le 1\) に制限されている場合の波動関数 \(u(x)\) として正しいものを選べ。

\(\int_{-1}^{1} e^{ikx} dk = \left[\frac{e^{ikx}}{ix}\right]_{-1}^{1} = \frac{2\sin x}{x}\) となるため、全体で \(\sqrt{\frac{2}{\pi}} \frac{\sin x}{x}\) となります。

[2] 1次元ポテンシャル障壁の散乱

高さ \(V_0 = 2E\) の障壁に対するトンネル効果と透過・反射係数。

Q3(b) 障壁内部 (\(0 \le x \le a\)) の波動関数の形

ポテンシャル \(V(x) = 2E\) である領域2における波動関数 \(u_2(x)\) の一般解として正しいものはどれか。

Schrödinger方程式は \(-\frac{\hbar^2}{2m_e}\frac{d^2u}{dx^2} + 2Eu = Eu \implies \frac{d^2u}{dx^2} = k^2 u\) となるため、解は虚数単位のつかない指数関数 \(B_1 e^{kx} + B_2 e^{-kx}\) となります。

Q4(d) ポテンシャル障壁の透過確率 \(T\)

この障壁を透過する確率 \(T = |C/A_1|^2\) の正確な式を選べ。

境界条件より \(A_1 = C e^{ika} [\cosh(ka) - i\sinh(ka)]\) となり、その絶対値2乗は \(|A_1/C|^2 = \cosh^2(ka) + \sinh^2(ka) = 1 + 2\sinh^2(ka)\) と計算されるため、逆数をとると \(T = \frac{1}{1 + 2\sinh^2(ka)}\) になります。

[3] 3次元中心力場と水素原子

球面座標系における波動関数と球面調和関数・極限挙動。

Q5(d) 球面調和関数 \(Y_{2,0}(\theta, \phi)\) の形

\((l,m) = (2,0)\) の場合の球面調和関数 \(Y_{2,0}\)（\(\cos\theta\) の関数）として正しいものはどれか。

ルジャンドル多項式 \(P_2(\cos\theta) = \frac{1}{2}(3\cos^2\theta - 1)\) に規格化定数を乗じることで \(Y_{2,0} = \sqrt{\frac{5}{16\pi}} (3\cos^2\theta - 1)\) が得られます。

Q6(e) \(|Y_{2,0}|\) のプロット形状

\(x-z\) 平面における \(|Y_{2,0}|\) の形状として適切な選択肢はどれか（右図のア〜オより）。

\(Y_{2,0}\) は化学でも馴染み深い \(d_{z^2}\) 軌道の角度部分です。z軸方向に大きな上下ローブを持ち、\(\theta \approx 54.7^\circ\) で節（0）を通り、赤道（xy平面）付近に小さな輪っか（膨らみ）を持つ (ウ) が正解です。

Q7(g) 動径関数の原点極限 \(r \to 0\)

\(\chi(r) = r R(r)\) の \(r \to 0\) における漸近挙動として正しいものを選べ。

\(r \to 0\) では遠心力項が支配的となり、\(r^2 \frac{d^2\chi}{dr^2} - l(l+1)\chi = 0\) を得ます。\(\chi(r) = r^s\) を試行すると \(s = l+1, -l\) となりますが、原点で波動関数が発散しない（規格化可能である）条件より \(s = l+1\) つまり \(\chi(r) \propto r^{l+1}\)（すなわち \(R(r) \propto r^l\)）となります。
