[1] 波動関数と重み関数（フーリエ変換）

逆フーリエ変換の定義式を使って、波数空間の表現を空間の波動関数へと変換します。

問[1](a)Step 1定義式の代入

使用する定義式（問題文より） \[ u(x) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{\infty} d k \, e^{i k x} \hat{u}(k) \]

重み関数が \(\hat{u}(k) = \frac{1}{\sqrt{2\pi}}\)（定数）で与えられたとき、上の定義式に代入して整理した積分式はどれか。

\(\hat{u}(k)\) の位置に \(\frac{1}{\sqrt{2\pi}}\) を代入すると、定数項が \(\frac{1}{\sqrt{2\pi}} \times \frac{1}{\sqrt{2\pi}} = \frac{1}{2\pi}\) となり積分の前線へ出ます。

問[1](a)Step 2デルタ関数の同定

デルタ関数のフーリエ表現 \[ \delta(x) = \frac{1}{2\pi} \int_{-\infty}^{\infty} e^{i k x} d k \]

Step 1 で得られた式 \(\frac{1}{2\pi} \int_{-\infty}^{\infty} e^{i k x} d k\) の積分結果として正しい表現を選べ。

この積分はディラックのデルタ関数 \(\delta(x)\) そのものです。すべての波数が等しく重なり合うと、原点 \(x=0\) に完全に局所化した状態になります。

問[1](b)Step 3有限積分の実行

計算のヒント公式 \[ \int_{-1}^{1} e^{i k x} d k = \left[ \frac{e^{i k x}}{i x} \right]_{-1}^{1} = \frac{e^{i x} - e^{-i x}}{i x} = \frac{2 \sin x}{x} \]

\(\hat{u}(k) = 1 \; (|k| \le 1)\) のとき、\(u(x) = \frac{1}{\sqrt{2\pi}} \int_{-1}^{1} e^{i k x} d k\) を計算した最終結果はどれか。

オイラーの公式より \(e^{ix} - e^{-ix} = 2i \sin x\) です。係数 \(\frac{1}{\sqrt{2\pi}}\) とあわせて \(\frac{2}{\sqrt{2\pi}} \frac{\sin x}{x} = \sqrt{\frac{2}{\pi}} \frac{\sin x}{x}\) と導かれます。

[2] 1次元ポテンシャル障壁の散乱

高さ \(V_0 = 2E\) の障壁に対する領域別の方程式と境界接続を展開します。

問[2](a)(b)Step 4障壁内部の方程式

領域2 (\(0 \le x \le a\)) のSchrödinger方程式 \[ \left[ -\frac{\hbar^2}{2m_e} \frac{d^2}{dx^2} + 2E \right] u(x) = E u(x) \quad \left( k = \frac{\sqrt{2m_e E}}{\hbar} \right) \]

上の式を整理したとき、\( \frac{d^2 u}{dx^2} \) の右辺として正しい形を選べ。

\(2E u\) を右辺へ移項すると \(E u - 2E u = -E u\) になります。両辺に \(-\frac{2m_e}{\hbar^2}\) を掛けると、右辺は \(+\frac{2m_e E}{\hbar^2} u = k^2 u\) （正の係数）になります。

問[2](c)Step 5\(x=a\) での接続条件

境界条件（値と1階微分の連続） \[ u_2(a) = u_3(a), \quad u'_2(a) = u'_3(a) \] \[ \left[ \text{但し } u_2(x) = B_1 e^{kx} + B_2 e^{-kx}, \quad u_3(x) = C e^{ikx} \right] \]

\(x=a\) における接続条件から導かれる連立方程式として正しい組を選べ。

微分式は \(k(B_1 e^{ka} - B_2 e^{-ka}) = ik C e^{ika}\) となり、両辺を共通係数 $k$ で割ることで \(B_1 e^{ka} - B_2 e^{-ka} = i C e^{ika}\) が得られます。

問[2](d)Step 6振幅の比の絶対値2乗

導出された振幅の関係と公式 \[ A_1 = C e^{ika} \left[ \cosh(ka) - i \sinh(ka) \right] \] \[ \text{双曲線関数の性質: } \cosh^2 x - \sinh^2 x = 1 \]

上式から透過確率の分母となる \(\left| \frac{A_1}{C} \right|^2\) を計算した結果を選べ。

\(|e^{ika}|^2 = 1\) であり、\(|\cosh(ka) - i\sinh(ka)|^2 = \cosh^2(ka) + \sinh^2(ka)\) となります。\(\cosh^2(ka) = 1 + \sinh^2(ka)\) を代入すれば \(1 + 2\sinh^2(ka)\) と計算できます。

[3] 3次元中心力場と水素原子

角度依存関数 \(\Phi(\phi)\), \(Y_{l,m}\) および動径関数 \(\chi(r)\) の限界挙動です。

問[3](a)〜(c)Step 7方位角関数 \(\Phi(\phi)\) の決定

条件式 \[ \text{微分方程式: } \frac{d\Phi}{d\phi} = i m \Phi \implies \text{一般解: } \Phi(\phi) = C e^{im\phi} \] \[ \text{周期条件: } \Phi(\phi+2\pi) = \Phi(\phi), \quad \text{規格化: } \int_0^{2\pi} |\Phi(\phi)|^2 d\phi = 1 \]

条件をすべて満たす規格化済み関数 \(\Phi(\phi)\) として正しいものを選べ。

\(e^{im2\pi} = 1\) より \(m\) は整数。\(|C|^2 \int_0^{2\pi} d\phi = 2\pi |C|^2 = 1 \implies C = \frac{1}{\sqrt{2\pi}}\) と決定されます。

問[3](d)(e)Step 8球面調和関数のノード評価

球面調和関数 \(Y_{2,0}\) の形 \[ Y_{2,0}(\theta) = \sqrt{\frac{5}{16\pi}} (3\cos^2\theta - 1) \]

\(Y_{2,0}\) の形と節（ゼロ点）に関する記述のうち正しいものを選べ。

\(\cos\theta = \pm 1\) で最大値 \(3(1)-1=2\) となり、\(3\cos^2\theta - 1 = 0 \implies \cos\theta = \pm 1/\sqrt{3}\)（約 \(54.7^\circ\)）の円錐方向でゼロ点（節）となります。これが $d_{z^2}$ 軌道の特性です。

問[3](f)Step 9遠方極限 \(r \to \infty\) の物理的選択

遠方極限の方程式と一般解 (\(E < 0\)) \[ \frac{d^2\chi}{dr^2} = \beta^2 \chi \quad \left( \beta = \frac{\sqrt{-2m_e E}}{\hbar} > 0 \right) \implies \chi(r) = C_1 e^{-\beta r} + C_2 e^{\beta r} \]

物理的な束縛条件（\(r \to \infty\) で \(\chi(r) \to 0\)）を満たす正解を選べ。

波動関数が遠方で無限大へ発散しないため \(C_2 = 0\) となり、指数関数的に減衰する \(e^{-\beta r}\) 項のみが残ります。

問[1] まとめ波動関数とフーリエ変換

1. 逆フーリエ変換の基本公式:

\[ u(x) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{\infty} d k \, e^{i k x} \hat{u}(k) \]

2. ディラックのデルタ関数 \(\delta(x)\) のフーリエ表現:

\[ \delta(x) = \frac{1}{2\pi} \int_{-\infty}^{\infty} e^{i k x} d k \]

★あらゆる波数が等しい重み（\(\hat{u}(k)=\text{定数}\)）で重なると、実空間では完全局所化したデルタ関数になる。

3. 矩形波束の変換（Sinc関数）:

波数幅が \(|k| \le 1\) に限られるとき、波動関数は \(u(x) = \sqrt{\frac{2}{\pi}} \frac{\sin x}{x}\) となる。

問[2] まとめ1次元ポテンシャル障壁とトンネル効果

1. 領域ごとの解の型 (\(V_0 = 2E > E\)):

・障壁の外 (\(V=0\)): 振動解 \(e^{\pm i k x}\) （但し \(k = \frac{\sqrt{2m_e E}}{\hbar}\)）
・障壁の内部 (\(V=2E\)): 減衰/増大解 \(e^{\pm k x}\) （実数指数）

2. 境界接続（滑らかな接続）:

境界 \(x=0, a\) において、① 波動関数の値 \(u(x)\) の連続、② 1階微分 \(u'(x)\) の連続 を課す。

3. 透過率 \(T\) と反射率 \(R\) の公式:

\[ T = \left|\frac{C}{A_1}\right|^2 = \frac{1}{1 + 2\sinh^2(ka)}, \quad R = \left|\frac{A_2}{A_1}\right|^2 = \frac{2\sinh^2(ka)}{1 + 2\sinh^2(ka)} \]

問[3] まとめ3次元水素原子と球面調和関数

1. 方位角関数 \(\Phi(\phi)\):

・方程式: \(\frac{d\Phi}{d\phi} = i m \Phi \implies \Phi(\phi) = \frac{1}{\sqrt{2\pi}} e^{im\phi}\)
・周期境界条件 \(\Phi(\phi+2\pi)=\Phi(\phi)\) より、磁気量子数 \(m\) は整数。

2. 球面調和関数 \(Y_{l,m}(\theta, \phi)\) の形状:

・\((l,m) = (2,0)\) のとき: \(Y_{2,0}(\theta) = \sqrt{\frac{5}{16\pi}} (3\cos^2\theta - 1)\)
・形状: \(d_{z^2}\) 軌道。z軸方向（\(\theta=0, \pi\)）に主ローブ、\(\theta \approx 54.7^\circ\) に節（ゼロ点円錐）を持つ。

3. 動径関数 \(\chi(r) = r R(r)\) の極限挙動:

・遠方極限 (\(r \to \infty\)): 束縛条件 (\(E < 0\)) より指数減衰 \(\chi(r) \propto e^{-\beta r}\) （\(\beta = \frac{\sqrt{-2m_e E}}{\hbar}\)）。
・原点極限 (\(r \to 0\)): 遠心力ポテンシャル項が支配的となり \(\chi(r) \propto r^{l+1}\) （即ち \(R(r) \propto r^l\)）。
