01 背景とSchrödinger方程式の無次元化

なぜ調和振動子を学ぶのか？ 古典的背景から微分方程式の無次元化までの完全な導出過程。

古典・物理的背景調和振動子の普遍性 [p.1, 2]

古典力学において、バネの復元力 \(F = -kx\) を受ける物体の運動方程式は \(m \ddot{x} = -kx\) で与えられ、角振動数 \(\omega = \sqrt{k/m}\) の単振動をする[cite: 2]。このときポテンシャルエネルギーは以下で表される[cite: 2]：

\[ V(x) = \frac{1}{2} k x^2 = \frac{1}{2} m \omega^2 x^2 \]
なぜ重要なポテンシャルなのか？
任意のポテンシャル \(V(x)\) を安定点（つり合いの点 \(x=0\), 即ち \(V'(0)=0\)）のまわりでテイラー展開すると[cite: 2]： \[ V(x) = V(0) + \cancel{V'(0)x} + \frac{V''(0)}{2!}x^2 + \mathcal{O}(x^3) \] 基準のエネルギーを \(V(0)=0\) に選べば、微小振動においては第一非ゼロ項である 2 次の項（＝調和振動子）で近似できる[cite: 2]。ばねや振り子のみならず、分子間力（Lennard-Jonesポテンシャルの底付近）や場の量子論など、物理の至る所で現れる超重要モデルである[cite: 2]。

無次元化無次元変数の導出ステップ [p.3]

時間に依存しないSchrödinger方程式は以下の通りである[cite: 2]：

\[ \left[ -\frac{\hbar^2}{2m}\frac{d^2}{dx^2} + \frac{1}{2}m\omega^2 x^2 \right] u(x) = E u(x) \]

定数 \(\hbar, m, \omega\) から「長さの次元 \([m]\)」を持つ物理量 \(\lambda\) を作ると[cite: 2]：

\[ [\lambda] = [\hbar]^a [m]^b [\omega]^c \implies \lambda = \sqrt{\frac{\hbar}{m\omega}} \]

無次元位置座標 \(\xi \equiv \frac{x}{\lambda}\) を導入し、微分演算子を変換する[cite: 2]：

\[ \frac{d}{dx} = \frac{d\xi}{dx}\frac{d}{d\xi} = \frac{1}{\lambda}\frac{d}{d\xi} \implies \frac{d^2}{dx^2} = \frac{1}{\lambda^2}\frac{d^2}{d\xi^2} \]

これを元のSchrödinger方程式に代入して整理する[cite: 2]：

\[ \left[ -\frac{\hbar^2}{2m\lambda^2}\frac{d^2}{d\xi^2} + \frac{1}{2}m\omega^2\lambda^2\xi^2 \right] \Phi(\xi) = E \Phi(\xi) \]

\(\lambda^2 = \frac{\hbar}{m\omega}\) を代入すると、第1項の係数は \(\frac{\hbar^2}{2m \cdot \frac{\hbar}{m\omega}} = \frac{\hbar\omega}{2}\)、第2項の係数は \(\frac{1}{2}m\omega^2 \cdot \frac{\hbar}{m\omega} = \frac{\hbar\omega}{2}\) となり、両辺が完璧に揃う[cite: 2]：

\[ \frac{\hbar\omega}{2} \left[ -\frac{d^2}{d\xi^2} + \xi^2 \right] \Phi(\xi) = E \Phi(\xi) \implies \left[ \frac{d^2}{d\xi^2} + (\epsilon - \xi^2) \right] \Phi(\xi) = 0 \]

ここで無次元エネルギーパラメータ \(\epsilon\) を次のように定義した[cite: 2]：

\[ \epsilon \equiv \frac{2E}{\hbar\omega} \qquad \left( \iff E = \frac{\hbar\omega}{2}\epsilon \right) \]

02 漸近形とHermiteの微分方程式

無限遠での波動関数の振る舞いを抽出し、多項式部分 \(H(\xi)\) に対する方程式を導出する。

漸近挙動無限遠 \(|\xi| \to \infty\) での振る舞い [p.4]

無次元方程式 \(\left[\frac{d^2}{d\xi^2} + (\epsilon - \xi^2)\right]\Phi(\xi) = 0\) において、遠方 \(|\xi| \gg \epsilon\) では \(\epsilon\) を無視できるため[cite: 2]：

\[ \left[ \frac{d^2}{d\xi^2} - \xi^2 \right] \Phi(\xi) \approx 0 \]

解の形を \(\Phi(\xi) \sim e^{a\xi^2}\) と予想して代入してみる[cite: 2]：

\[ \Phi' = 2a\xi e^{a\xi^2}, \quad \Phi'' = (2a + 4a^2\xi^2) e^{a\xi^2} \implies (2a + 4a^2\xi^2 - \xi^2) e^{a\xi^2} \approx (4a^2 - 1)\xi^2 e^{a\xi^2} = 0 \]

\(4a^2 - 1 = 0 \implies a = \pm 1/2\) となる[cite: 2]。束縛状態の物理的条件（無限遠で波動関数が発散しない \(\Phi(|\xi|\to\infty) \to 0\)）を満たすのは \(a = -1/2\) のみである[cite: 2]。したがって、一般解を次のように置く[cite: 2]：

\[ \Phi(\xi) = H(\xi) e^{-\xi^2/2} \]

導出Hermite微分方程式の変形 [p.5]

\(\Phi(\xi) = H(\xi) e^{-\xi^2/2}\) を元の微分方程式に代入するため、1階および2階微分を計算する[cite: 2]：

\[ \begin{aligned} \Phi' &= (H' - \xi H) e^{-\xi^2/2} \\ \Phi'' &= \left[ (H'' - H - \xi H') - \xi(H' - \xi H) \right] e^{-\xi^2/2} \\ &= \left[ H'' - 2\xi H' + (\xi^2 - 1) H \right] e^{-\xi^2/2} \end{aligned} \]

これを \(\Phi'' + (\epsilon - \xi^2)\Phi = 0\) に代入する[cite: 2]：

\[ \left[ H'' - 2\xi H' + (\xi^2 - 1) H + (\epsilon - \xi^2) H \right] e^{-\xi^2/2} = 0 \]

\(e^{-\xi^2/2} \neq 0\) より、\(H(\xi)\) が満たすべき **Hermite（エルミート）の微分方程式** が導かれる[cite: 2]：

\[ H'' - 2\xi H' + (\epsilon - 1) H = 0 \]

03 級数解の収束性とエネルギーの量子化

なぜエネルギーは離散的になるのか？ 無限級数の発散証明から量子化条件への論理ステップ。

級数展開冪級数解と漸化式 [p.6]

\(H(\xi)\) を冪級数 \(H(\xi) = \sum_{n=0}^{\infty} a_n \xi^n\) と仮定してHermite方程式に代入する[cite: 2]：

\[ \sum_{n=2}^{\infty} n(n-1)a_n \xi^{n-2} - 2\xi \sum_{n=1}^{\infty} n a_n \xi^{n-1} + (\epsilon - 1) \sum_{n=0}^{\infty} a_n \xi^n = 0 \]

第1項のダミーインデックスを \(n \to n+2\) にずらして \(\xi^n\) でまとめる[cite: 2]：

\[ \sum_{n=0}^{\infty} \left[ (n+2)(n+1)a_{n+2} + (\epsilon - 2n - 1)a_n \right] \xi^n = 0 \]

これが任意の \(\xi\) で成立するために、各次数の係数が 0 でなければならない。これにより**漸化式**を得る[cite: 2]：

\[ a_{n+2} = \frac{2n + 1 - \epsilon}{(n+2)(n+1)} a_n \]

※ \(a_0\) を決めると偶数次のみの系列（偶関数解）、\(a_1\) を決めると奇数次のみの系列（奇関数解）が独立に決まる。これはポテンシャルの偶関数対称性（パリティ）と合致する[cite: 2]。

発散証明なぜ無限級数のままではダメなのか？ [p.7]

\(n\) が非常に大きい（\(n \gg 1\)）とき、漸化式の比率は次のように振る舞う[cite: 2]：

\[ \frac{a_{n+2}}{a_n} = \frac{2n + 1 - \epsilon}{(n+2)(n+1)} \xrightarrow[n \to \infty]{} \frac{2n}{n^2} = \frac{2}{n} \]

一方で、\(e^{\xi^2}\) のテイラー展開 \(\sum_{k=0}^{\infty} \frac{\xi^{2k}}{k!}\) の係数 \(c_{2k} = \frac{1}{k!}\) の比率を計算してみると：

\[ \frac{c_{2k+2}}{c_{2k}} = \frac{k!}{(k+1)!} = \frac{1}{k+1} \approx \frac{1}{k} = \frac{2}{n} \quad (n=2k) \]

つまり、無限級数がどこまでも続くと大極限で \(H(\xi) \sim e^{\xi^2}\) と振る舞ってしまう[cite: 2]！ すると全波動関数は[cite: 2]：

\[ \Phi(\xi) = H(\xi) e^{-\xi^2/2} \sim e^{\xi^2} e^{-\xi^2/2} = e^{+\xi^2/2} \xrightarrow[|\xi|\to\infty]{} \infty \]

となり、物理的に許されない発散解となってしまう[cite: 2]。したがって、**\(H(\xi)\) は無限級数ではなく、途中の次数で打ち切られる有限多項式（Hermite多項式）でなければならない**[cite: 2]。

量子化固有値の打ち切り条件 [p.8, 9]

級数が最高次 \(n = n_*\) で止まる（\(a_{n_*+2} = 0\) となる）ためには、分子が 0 になればよい[cite: 2]：

\[ 2n_* + 1 - \epsilon = 0 \implies \epsilon = 2n_* + 1 \quad (n_* = 0, 1, 2, \dots) \]

\(\epsilon = \frac{2E}{\hbar\omega}\) を代入してエネルギー \(E\) について解く[cite: 2]：

\[ \frac{2E}{\hbar\omega} = 2n_* + 1 \implies E_m = \hbar\omega \left( m + \frac{1}{2} \right) \quad (m = 0, 1, 2, \dots) \]
零点エネルギー（Zero-point energy）：
基底状態（\(m=0\)）であっても、エネルギーは 0 にならず \(E_0 = \frac{1}{2}\hbar\omega\) を持つ[cite: 2]。これは不確定性原理 \(\Delta x \cdot \Delta p \ge \hbar/2\) に起因し、量子力学粒子が完全に停止して一定点に留まることができないことを意味している。

04 演習問題7 詳細解説と検算

スライド p.10 演習問題7（Hermite多項式の具体形と固有関数の直交性）のステップ解説。

演習7 問1Hermite多項式 \(H(\xi)\) の具体的な導出 [p.10]

初期条件 \(a_0 = a_1 = 1\) および漸化式 \(a_{n+2} = \frac{2n + 1 - \epsilon}{(n+2)(n+1)} a_n\) を用いて各 \(\epsilon\) で具体形を求める[cite: 2]。解を有限項で止める条件は \(\epsilon = 2n_* + 1\) である[cite: 2]。

① \(\epsilon = 1\) （\(n_* = 0\): 偶関数解）
打ち切り次数 \(n_* = 0\) より \(a_2 = \frac{0+1-1}{2 \cdot 1} a_0 = 0\)。偶数系列は \(a_0 = 1\) のみで停止。奇数系列は条件より遮断するため[cite: 2]：

\[ H_0(\xi) = 1 \]

② \(\epsilon = 3\) （\(n_* = 1\): 奇関数解）
打ち切り次数 \(n_* = 1\) より \(a_3 = \frac{2+1-3}{3 \cdot 2} a_1 = 0\)。奇数系列は \(a_1 = 1\) のみで停止[cite: 2]：

\[ H_1(\xi) = \xi \]

③ \(\epsilon = 5\) （\(n_* = 2\): 偶関数解）
打ち切り次数 \(n_* = 2\) より \(a_2 = \frac{0+1-5}{2 \cdot 1} a_0 = -2 a_0 = -2\)。次項は \(a_4 = \frac{4+1-5}{4 \cdot 3} a_2 = 0\) で停止[cite: 2]：

\[ H_2(\xi) = a_0 + a_2 \xi^2 = 1 - 2\xi^2 \]

④ \(\epsilon = 7\) （\(n_* = 3\): 奇関数解）
打ち切り次数 \(n_* = 3\) より \(a_3 = \frac{2+1-7}{3 \cdot 2} a_1 = -\frac{4}{6} a_1 = -\frac{2}{3}\)。次項は \(a_5 = 0\) で停止[cite: 2]：

\[ H_3(\xi) = a_1 \xi + a_3 \xi^3 = \xi - \frac{2}{3}\xi^3 \]
検算（Hermite微分方程式への代入確認）：
\(H_2(\xi) = 1 - 2\xi^2\) を \(H'' - 2\xi H' + (\epsilon - 1)H = 0 \quad (\epsilon=5)\) に代入してみる：
\(H_2' = -4\xi\), \(H_2'' = -4\)
左辺 \(= (-4) - 2\xi(-4\xi) + (5 - 1)(1 - 2\xi^2) = -4 + 8\xi^2 + 4 - 8\xi^2 = 0\)。確かに完全に成立する！

演習7 問2固有関数の直交性の証明 [p.10]

異なるエネルギー固有値に属する固有関数 \(\Phi_n(\xi) = H_n(\xi) e^{-\xi^2/2}\) 同士の直交性を証明する[cite: 2]：

例：\(n=0\) (\(E_0 = \frac{1}{2}\hbar\omega\)) と \(n=1\) (\(E_1 = \frac{3}{2}\hbar\omega\)) の直交性積分の評価

\[ \begin{aligned} \langle \Phi_0 | \Phi_1 \rangle &= \int_{-\infty}^{\infty} \Phi_0(\xi) \Phi_1(\xi) d\xi \\ &= \int_{-\infty}^{\infty} (1 \cdot e^{-\xi^2/2}) \cdot (\xi \cdot e^{-\xi^2/2}) d\xi = \int_{-\infty}^{\infty} \xi e^{-\xi^2} d\xi \end{aligned} \]

被積分関数 \(f(\xi) = \xi e^{-\xi^2}\) は \(f(-\xi) = -\xi e^{-(-\xi)^2} = -f(\xi)\) となり**奇関数**である。左右対称な区間 \((-\infty, \infty)\) での奇関数の定積分は厳密に 0 になる[cite: 2]：

\[ \int_{-\infty}^{\infty} \xi e^{-\xi^2} d\xi = 0 \implies \Phi_0 \text{ と } \Phi_1 \text{ は直交する} \]

一般の \(n \neq m\) に対する代数的検算（Sturm-Liouville型自作証明）：
\(\Phi_n'' + (\epsilon_n - \xi^2)\Phi_n = 0\) および \(\Phi_m'' + (\epsilon_m - \xi^2)\Phi_m = 0\) に対し、前者に \(\Phi_m\)、後者に \(\Phi_n\) を掛けて辺々引き算する：

\[ \Phi_m \Phi_n'' - \Phi_n \Phi_m'' + (\epsilon_n - \epsilon_m)\Phi_n \Phi_m = 0 \implies \frac{d}{d\xi}(\Phi_m \Phi_n' - \Phi_n \Phi_m') = (\epsilon_m - \epsilon_n)\Phi_n \Phi_m \]

これを全空間で積分すると、左辺は境界条件 \(\Phi_n(\pm\infty) = 0\) より 0 となるため、\(\epsilon_n \neq \epsilon_m\) である限り \(\int_{-\infty}^{\infty} \Phi_n \Phi_m d\xi = 0\) が常に保証される！

05 要点まとめシート

第8講の論理構造と重要公式の全体系総まとめ。

まとめ一次元調和振動子の解法ロードマップ [p.9]

1. 方程式と無次元化:

・ポテンシャル: \(V(x) = \frac{1}{2}m\omega^2 x^2\)[cite: 2]
・長さスケール: \(\lambda = \sqrt{\frac{\hbar}{m\omega}}\)[cite: 2]
・無次元Schrödinger方程式: \(\left[ \frac{d^2}{d\xi^2} + (\epsilon - \xi^2) \right] \Phi(\xi) = 0 \quad \left( \epsilon = \frac{2E}{\hbar\omega} \right)\)[cite: 2]

2. 漸近分離とHermite方程式:

・波動関数の分離: \(\Phi(\xi) = H(\xi) e^{-\xi^2/2}\)[cite: 2]
・Hermiteの微分方程式: \(H'' - 2\xi H' + (\epsilon - 1) H = 0\)[cite: 2]
・展開係数の漸化式: \(a_{n+2} = \frac{2n + 1 - \epsilon}{(n+2)(n+1)} a_n\)[cite: 2]

3. 収束条件とエネルギーの量子化:

・無限級数のままだと \(H(\xi) \sim e^{\xi^2} \implies \Phi(\xi) \sim e^{\xi^2/2} \to \infty\) となり発散するため、有限多項式で打ち切る必要がある[cite: 2]。
・打ち切り条件: \(\epsilon = 2m + 1 \quad (m = 0, 1, 2, \dots)\)[cite: 2]
・固有エネルギー: \(E_m = \hbar\omega \left( m + \frac{1}{2} \right)\)[cite: 2]
・基底状態エネルギー（零点エネルギー）: \(E_0 = \frac{1}{2}\hbar\omega \neq 0\)[cite: 2]

4. Hermite多項式 \(H_m(\xi)\) と固有関数の性質:

・固有関数: \(\Phi_m(\xi) = N_m H_m(\xi) e^{-\xi^2/2}\)[cite: 2]
・パリティ交互構造: \(m\) が偶数 $\to$ 偶関数、\(m\) が奇数 $\to$ 奇関数[cite: 2]
・直交性: \(\int_{-\infty}^{\infty} \Phi_n(\xi) \Phi_m(\xi) d\xi = 0 \quad (n \neq m)\)[cite: 2]
