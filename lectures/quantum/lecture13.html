01 確率の流れの密度 \(\boldsymbol{j}\) と連続の式

非束縛系における存在確率保存則 \(\frac{\partial\rho}{\partial t} + \nabla \cdot \boldsymbol{j} = 0\) の完全証明（p.2, 3）。

p.2確率密度 \(\rho\) の時間変化と流束 \(\boldsymbol{j}\)

確率密度 \(\rho = |\psi|^2 = \psi^* \psi\) の時間変化をSchrödinger方程式 \(i\hbar \frac{\partial\psi}{\partial t} = -\frac{\hbar^2}{2m}\nabla^2\psi + V\psi\) を用いて微分する[cite: 7]：

\[ \frac{\partial\rho}{\partial t} = \frac{\partial\psi^*}{\partial t}\psi + \psi^*\frac{\partial\psi}{\partial t} \]
\[ = \left( \frac{i\hbar}{2m}\nabla^2\psi^* + \frac{i}{\hbar}V\psi^* \right)\psi + \psi^*\left( -\frac{i\hbar}{2m}\nabla^2\psi - \frac{i}{\hbar}V\psi \right) \]

ポテンシャル項 \(V\psi^*\psi\) は相殺し、次のように変形される[cite: 7]：

\[ \frac{\partial\rho}{\partial t} = -\nabla \cdot \left[ \frac{i\hbar}{2m} (\psi \nabla\psi^* - \psi^* \nabla\psi) \right] \]

ここで**確率の流れの密度 \(\boldsymbol{j}\)** を定義すると、連続の式を得る[cite: 7]：

\[ \frac{\partial\rho}{\partial t} + \nabla \cdot \boldsymbol{j} = 0, \qquad \boldsymbol{j} = \frac{i\hbar}{2m}(\psi \nabla\psi^* - \psi^* \nabla\psi) = -\frac{\hbar}{m}\text{Im}\left[\psi^* \nabla\psi\right] \]

p.3ガウスの発散定理による確率保存

空間領域 \(V\) で体積分し、ガウスの定理を適用する[cite: 7]：

\[ \frac{\partial}{\partial t}\int_V \rho dV = -\int_S \boldsymbol{j} \cdot \boldsymbol{n} dS \implies \frac{\partial P_V}{\partial t} = -\int_S \boldsymbol{j} \cdot \boldsymbol{n} dS \]

※領域 \(V\) から粒子が流出すると領域内確率 \(P_V\) は減少する（確率の局所保存則）[cite: 7]。

02 ポテンシャル障壁と領域別の解

幅 \(2a\)、高さ \(V_0\) の障壁に対する波動関数の設定（p.4, 5, 6）。

p.4, 5ポテンシャル \(V(x)\) と各領域の解 (\(E < V_0\))

\[ V(x) = \begin{cases} V_0 & (|x| \le a) \\ 0 & (|x| > a) \end{cases} \]

領域1 (\(x < -a\)): 入射波＋反射波[cite: 7]

\[ u_1(x) = A_1 e^{ikx} + A_2 e^{-ikx} \qquad \left( k = \frac{\sqrt{2mE}}{\hbar} \right) \]

領域2 (\(|x| \le a\)): 障壁内部（減衰・増大）[cite: 7]

\[ u_2(x) = B_1 e^{\kappa x} + B_2 e^{-\kappa x} \qquad \left( \kappa = \frac{\sqrt{2m(V_0-E)}}{\hbar} \right) \]

領域3 (\(x > a\)): 透過波のみ[cite: 7]

\[ u_3(x) = C e^{ikx} \]

p.6境界条件（\(x = \pm a\) での滑らかな接続）

\[ x = -a: \quad A_1 e^{-ika} + A_2 e^{ika} = B_1 e^{-\kappa a} + B_2 e^{\kappa a} \]
\[ ik(A_1 e^{-ika} - A_2 e^{ika}) = \kappa(B_1 e^{-\kappa a} - B_2 e^{\kappa a}) \]
\[ x = +a: \quad C e^{ika} = B_1 e^{\kappa a} + B_2 e^{-\kappa a} \]
\[ ik C e^{ika} = \kappa(B_1 e^{\kappa a} - B_2 e^{-\kappa a}) \]

03 透過率 \(T\) と反射率 \(R\) の導出

流束密度比による透過率 \(T = j_T/j_I\) と反射率 \(R = j_R/j_I\) の計算（p.7）。

p.7流束密度と係数関係

各流束は \(j_I = \frac{\hbar k}{m}|A_1|^2, \, j_R = \frac{\hbar k}{m}|A_2|^2, \, j_T = \frac{\hbar k}{m}|C|^2\)[cite: 7]。境界条件より[cite: 7]：

\[ A_1 = \frac{e^{2ika}C}{2}\left[ 2\cosh(2\kappa a) - i\left(\frac{k}{\kappa} - \frac{\kappa}{k}\right)\sinh(2\kappa a) \right] \]
\[ A_2 = \frac{C}{2}\left[ -i\left(\frac{k}{\kappa} + \frac{\kappa}{k}\right)\sinh(2\kappa a) \right] \]

透過率 \(T\) の導出：[cite: 7]

\[ T = \left|\frac{C}{A_1}\right|^2 = \frac{4}{4\cosh^2(2\kappa a) + \left(\frac{k}{\kappa} - \frac{\kappa}{k}\right)^2 \sinh^2(2\kappa a)} \]

\(\cosh^2(2\kappa a) = 1 + \sinh^2(2\kappa a)\) を代入して整理すると[cite: 7]：

\[ T = \frac{4k^2\kappa^2}{4k^2\kappa^2 + (k^2 + \kappa^2)^2 \sinh^2(2\kappa a)} \]
\[ R = \frac{(k^2 + \kappa^2)^2 \sinh^2(2\kappa a)}{4k^2\kappa^2 + (k^2 + \kappa^2)^2 \sinh^2(2\kappa a)} \qquad (\text{※ } T + R = 1 \text{ 確率保存}) \]

04 厚い障壁極限 ＆ 高エネルギー（\(E \ge V_0\)）共鳴透過

厚い壁でのトンネル効果指数減衰と、Ramsauer-Townsend効果（p.8, 9）。

p.8厚い障壁極限 \(2a\kappa \gg 1\)

\(\sinh(2\kappa a) \approx \frac{1}{2} e^{2\kappa a}\) と近似すると[cite: 7]：

\[ T \approx \frac{16 k^2 \kappa^2}{(k^2 + \kappa^2)^2} e^{-4\kappa a} \]

※壁幅 \(2a\) が増すか、ポテンシャル高さ \(V_0\) が増すと透過率は指数関数的に減衰する[cite: 7]。

p.9\(E \ge V_0\) （共鳴透過：Ramsauer-Townsend効果）

\(\kappa = i q\) （\(q = \frac{\sqrt{2m(E-V_0)}}{\hbar}\)）と置き、\(\sinh(2iqa) = i\sin(2qa)\) を代入する[cite: 7]：

\[ T = \frac{4k^2 q^2}{4k^2 q^2 + (k^2 - q^2)^2 \sin^2(2qa)} \]

\(2qa = n\pi \iff 2a = n \frac{\lambda}{2}\) のとき \(\sin(2qa) = 0\) となり、**完全透過 \(T=1, R=0\)** となる（**Ramsauer-Townsend効果**）[cite: 7]。

05 演習問題12 完全導出

4つの境界条件から係数 \(B_1, B_2, A_1, A_2\) を \(C\) で表す計算プロセス（p.12）。

p.12演習12：未定係数の連立方程式の完全解法

\(x=+a\) の2式：\(B_1 e^{\kappa a} + B_2 e^{-\kappa a} = C e^{ika}\)、\(B_1 e^{\kappa a} - B_2 e^{-\kappa a} = i\frac{k}{\kappa} C e^{ika}\) を足し引きする[cite: 7]：

\[ B_1 = e^{ika} \frac{C e^{-\kappa a}}{2}\left(1 + i\frac{k}{\kappa}\right), \qquad B_2 = e^{ika} \frac{C e^{\kappa a}}{2}\left(1 - i\frac{k}{\kappa}\right) \]

これを \(x=-a\) の2式に代入して整理すると \(A_1, A_2\) が導かれる[cite: 7]：

\[ A_1 = \frac{e^{2ika}C}{2}\left[ 2\cosh(2\kappa a) - i\left(\frac{k}{\kappa} - \frac{\kappa}{k}\right)\sinh(2\kappa a) \right] \]
\[ A_2 = \frac{C}{2}\left[ -i\left(\frac{k}{\kappa} + \frac{\kappa}{k}\right)\sinh(2\kappa a) \right] \]
