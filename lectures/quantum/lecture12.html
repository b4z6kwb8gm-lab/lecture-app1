01 動径方程式と標準形への変換

1階微分項を消去し、標準形 \(\chi''(r) + Q(r)\chi(r) = 0\) を導出する（p.2, 3）。

p.21階微分項の消去手順

中心力ポテンシャル系での動径方向の微分方程式[cite: 6]：

\[ \left[ -\frac{\hbar^2}{2mr^2}\frac{d}{dr}\left(r^2 \frac{d}{dr}\right) + V(r) + \frac{\hbar^2 l(l+1)}{2mr^2} \right] R(r) = E R(r) \]

これを整理すると \(R''(r) + \frac{2}{r}R'(r) + Q(r)R(r) = 0\) となる[cite: 6]。\(R(r) = f(r)\chi(r)\) を代入して \(f(r) = \frac{1}{r}\) を得ると標準形が導かれる[cite: 6]：

\[ \chi''(r) - \left[ \kappa^2 + \frac{2mV(r)}{\hbar^2} + \frac{l(l+1)}{r^2} \right] \chi(r) = 0 \qquad \left(\kappa^2 \equiv -\frac{2mE}{\hbar^2}\right) \]

p.3水素原子のCoulombポテンシャル

\[ V(r) = -\frac{e^2}{4\pi\epsilon_0 r} \]
\[ \chi''(r) - \left[ \kappa^2 - \frac{me^2}{2\pi\epsilon_0\hbar^2 r} + \frac{l(l+1)}{r^2} \right] \chi(r) = 0 \]

02 極限解（漸近解）の導出と試行解の決定

無限遠 \(r \to \infty\) と原点 \(r \to 0\) における挙動を抽出する（p.4, 5, 6）。

p.4無限遠極限 \(r \to \infty\) の挙動

\[ \chi''(r) \approx \kappa^2 \chi(r) \implies \chi(r) = A e^{-\kappa r} + B e^{\kappa r} \]
\[ \chi(r) \sim e^{-\kappa r} \quad (r \to \infty) \]

p.5原点極限 \(r \to 0\) の挙動（Euler型微分方程式）

\[ \chi''(r) - \frac{l(l+1)}{r^2}\chi(r) \approx 0 \implies \chi(r) = C r^{l+1} + D r^{-l} \]
\[ \chi(r) \sim r^{l+1} \quad (r \to 0) \]

p.6全領域の波動関数の分離

\[ \chi(r) = e^{-\kappa r} \tilde{L}(r) = e^{-\kappa r} r^{l+1} (c_0 + c_1 r + c_2 r^2 + \dots) \]

03 無次元化、級数展開、主量子数 \(n\) の導出

無次元変数 \(\rho = 2\kappa r\) への変換と、エネルギー量子化条件（p.7, 8）。

p.7無次元変数 \(\rho = 2\kappa r\) と展開係数の漸化式

\[ \left[ \frac{d^2}{d\rho^2} - \frac{d}{d\rho} + \frac{n}{\rho} - \frac{l(l+1)}{\rho^2} \right] L(\rho) = 0 \qquad \left( n \equiv \frac{me^2}{4\pi\epsilon_0\hbar^2\kappa} \right) \]
\[ c_{k+1} = c_k \frac{l + k + 1 - n}{(k+1)(2l + k + 2)} \]

p.8打ち切り条件とエネルギー固有値 \(E_n\)

\[ l + k_* + 1 - n = 0 \implies n = l + k_* + 1 \quad (n = 1, 2, 3, \dots) \]
\[ E_n = -\frac{\hbar^2}{2m r_0^2}\frac{1}{n^2} \approx -\frac{13.6 \text{ eV}}{n^2} \qquad \left(r_0 = \frac{4\pi\epsilon_0\hbar^2}{e^2 m} \approx 5.29 \times 10^{-11} \text{ m}\right) \]
