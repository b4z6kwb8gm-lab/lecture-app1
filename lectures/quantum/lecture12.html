01 動径方程式と標準形への変換

1階微分項を消去し、標準形 \(\chi''(r) + Q(r)\chi(r) = 0\) を導出する（p.2, 3）。

p.21階微分項の消去手順

中心力ポテンシャル系での動径方向の微分方程式[cite: 6]：

\[ \left[ -\frac{\hbar^2}{2mr^2}\frac{d}{dr}\left(r^2 \frac{d}{dr}\right) + V(r) + \frac{\hbar^2 l(l+1)}{2mr^2} \right] R(r) = E R(r) \]

これを整理すると \(R''(r) + \frac{2}{r}R'(r) + Q(r)R(r) = 0\) となる[cite: 6]。ただし \(Q(r) = -\frac{2m}{\hbar^2}\left(V(r) + \frac{\hbar^2 l(l+1)}{2mr^2} - E\right)\) である[cite: 6]。1階微分を削るため \(R(r) = f(r)\chi(r)\) を代入する[cite: 6]：

\[ f \chi'' + \left(2f' + \frac{2}{r}f\right)\chi' + \left(f'' + \frac{2}{r}f' + Qf\right)\chi = 0 \]

\(\chi'\) の係数を 0 にするため、\(2f' + \frac{2}{r}f = 0 \implies \frac{f'}{f} = -\frac{1}{r} \implies f(r) = \frac{1}{r}\) と定まる[cite: 6]。このとき第3項の括弧内は \(\frac{Q}{r}\) となるため、両辺に \(r\) を掛けると標準形を得る[cite: 6]：

\[ \chi''(r) + Q(r)\chi(r) = 0 \implies \chi''(r) - \left[ \kappa^2 + \frac{2mV(r)}{\hbar^2} + \frac{l(l+1)}{r^2} \right] \chi(r) = 0 \]

ここで \(\kappa^2 \equiv -\frac{2mE}{\hbar^2} > 0\) （束縛状態 \(E < 0\)）である[cite: 6]。

p.3水素原子のCoulombポテンシャル

原点に正電荷 \(+e\) の陽子があり、電子がクーロン力で束縛されている系のポテンシャル[cite: 6]：

\[ V(r) = -\frac{e^2}{4\pi\epsilon_0 r} \]

これを組み込むと、水素原子の \(\chi(r)\) に関する微分方程式が完成する[cite: 6]：

\[ \chi''(r) - \left[ \kappa^2 - \frac{me^2}{2\pi\epsilon_0\hbar^2 r} + \frac{l(l+1)}{r^2} \right] \chi(r) = 0 \]

02 極限解（漸近解）の導出と試行解の決定

無限遠 \(r \to \infty\) と原点 \(r \to 0\) における挙動を抽出する（p.4, 5, 6）。

p.4無限遠極限 \(r \to \infty\) の挙動

\(r \to \infty\) では \(\frac{1}{r}\) および \(\frac{1}{r^2}\) の項が減衰して無視できるため[cite: 6]：

\[ \chi''(r) \approx \kappa^2 \chi(r) \implies \chi(r) = A e^{-\kappa r} + B e^{\kappa r} \]

束縛条件（\(r \to \infty\) で \(\chi(r) \to 0\)）より \(B=0\) でなければならない[cite: 6]。したがって[cite: 6]：

\[ \chi(r) \sim e^{-\kappa r} \quad (r \to \infty) \]

p.5原点極限 \(r \to 0\) の挙動（Euler型微分方程式）

\(r \to 0\) では、最も急激に増加する遠心力項 \(\frac{l(l+1)}{r^2}\) が支配的となる[cite: 6]：

\[ \chi''(r) - \frac{l(l+1)}{r^2}\chi(r) \approx 0 \]

試行解 \(\chi(r) = r^k\) を代入すると \(k(k-1) - l(l+1) = 0 \implies k = l+1, -l\) を得る[cite: 6]。原点での規格化可能性（\(R = \frac{\chi}{r}\) が発散しない条件 \(\chi(0) = 0\)）より \(D=0\) となり[cite: 6]：

\[ \chi(r) \sim r^{l+1} \quad (r \to 0) \]

p.6全領域の波動関数の分離

両端での漸近形を組み合わせ、中間領域の多項式を \(\tilde{L}(r)\) として一般解を仮定する[cite: 6]：

\[ \chi(r) = e^{-\kappa r} \tilde{L}(r) = e^{-\kappa r} r^{l+1} (c_0 + c_1 r + c_2 r^2 + \dots) \]

03 無次元化、級数展開、主量子数 \(n\) の導出

無次元変数 \(\rho = 2\kappa r\) への変換と、エネルギー量子化条件（p.7, 8）。

p.7無次元変数 \(\rho = 2\kappa r\) と展開係数の漸化式

\(\chi(r) = e^{-\kappa r} \tilde{L}(r)\) を元の式に代入し、\(\rho = 2\kappa r\) と無次元化して \(L(\rho) = \tilde{L}\left(\frac{\rho}{2\kappa}\right)\) と置く[cite: 6]：

\[ \left[ \frac{d^2}{d\rho^2} - \frac{d}{d\rho} + \frac{n}{\rho} - \frac{l(l+1)}{\rho^2} \right] L(\rho) = 0 \qquad \left( \text{但し } n \equiv \frac{me^2}{4\pi\epsilon_0\hbar^2\kappa} \right) \]

\(L(\rho) = \sum_{k=0}^{\infty} c_k \rho^{l+k+1}\) と冪級数展開して代入すると、係数 \(c_k\) の漸化式が得られる[cite: 6]：

\[ c_{k+1} = c_k \frac{l + k + 1 - n}{(k+1)(2l + k + 2)} \]

p.8打ち切り条件とエネルギー固有値 \(E_n\)

級数が無限に続くと \(L(\rho) \sim e^{2\kappa r}\) となり、\(\chi(r) \sim e^{+\kappa r} \to \infty\) と発散する[cite: 6]。したがって、ある \(k = k_*\) で分子が 0 となり級数が有限項で止まらなければならない[cite: 6]：

\[ l + k_* + 1 - n = 0 \implies n = l + k_* + 1 \quad (k_* = 0, 1, 2, \dots) \]

\(l, k_*\) は非負の整数であるため、\(n\) は正の整数をとる（**主量子数 \(n = 1, 2, 3, \dots\)**）[cite: 6]。

\(\kappa_n = \frac{1}{n r_0}\) （Bohr半径 \(r_0 = \frac{4\pi\epsilon_0\hbar^2}{e^2 m} \approx 5.29 \times 10^{-11} \text{ m}\)）を定義すると、エネルギー固有値が導かれる[cite: 6]：

\[ E_n = -\frac{\hbar^2}{2m r_0^2}\frac{1}{n^2} \approx -\frac{13.6 \text{ eV}}{n^2} \]

04 Laguerre陪多項式とエネルギー準位の縮退

動径波動関数 \(R_{nl}(r)\) の解の構造と、\(n^2\) 重縮退の分類（p.9, 10, 11）。

p.9主量子数 \(n\) と方位量子数 \(l\) の関係・縮退度

\(n = l + k_* + 1 \ge l + 1\) より、固定された主量子数 \(n\) に対して許される \(l\) の範囲は限定される[cite: 6]：

\[ l = 0, 1, 2, \dots, n-1 \]

各 \(l\) に対して磁気量子数 \(m_l\) は \((2l+1)\) 個存在するため、主量子数 \(n\) に対する全状態数（縮退度）は \(n^2\) となる[cite: 6]：

\[ \sum_{l=0}^{n-1} (2l+1) = 1 + 3 + 5 + \dots + (2n-1) = n^2 \]

p.10動径波動関数 \(R_{nl}(r)\) の一般表式

多項式部分 \(L(\rho)\) は **Laguerreの陪多項式 \(L_{n+l}^{2l+1}(\rho)\)** に帰着する[cite: 6]。規格化条件 \(\int_0^\infty |R(r)|^2 r^2 dr = 1\) を満たす全表現は以下の通りである[cite: 6]：

\[ R_{nl}(r) = \frac{1}{\sqrt{r_0 N_{nl}}} \left(\frac{2}{n r_0}\right)^{l+1} e^{-r/nr_0} r^l L_{n+l}^{2l+1}\left(\frac{2r}{nr_0}\right) \]

基底状態 (\(n=1, l=0\)):[cite: 6]

\[ R_{10}(r) = 2 \left(\frac{1}{r_0}\right)^{3/2} e^{-r/r_0} \]

05 演習問題11 詳細解説と数値導出

Laguerre陪微分方程式の変換と、Bohr半径・基底状態エネルギーの数値計算（p.12, 13）。

p.12演習11 1.(a)(b)：\(g(\rho)\) の方程式とインデックス対応

(a) \(L(\rho) = \rho^{l+1} g(\rho)\) の代入導出：[cite: 6]

\(L' = (l+1)\rho^l g + \rho^{l+1} g'\)、\(L'' = (l+1)l\rho^{l-1} g + 2(l+1)\rho^l g' + \rho^{l+1} g''\) を方程式に代入して \rho^{l} で割る[cite: 6]：

\[ \rho g'' + (2l + 2 - \rho) g' + (n - l - 1) g = 0 \]

(b) Laguerre陪微分方程式 \([\rho \frac{d^2}{d\rho^2} + (b+1-\rho)\frac{d}{d\rho} + a-b] L_a^b(\rho) = 0\) との比較：[cite: 6]

\[ b + 1 = 2l + 2 \implies b = 2l + 1, \qquad a - b = n - l - 1 \implies a = n + l \]

これにより、解は \(g(\rho) = L_{n+l}^{2l+1}(\rho)\) と同定される[cite: 6]。

p.13演習11 3：Bohr半径 \(r_0\) と \(E_1\) の数値計算

定数：\(m = 9.109 \times 10^{-31} \text{ kg}\), \(e = 1.602 \times 10^{-19} \text{ C}\), \(\hbar = 1.055 \times 10^{-34} \text{ J}\cdot\text{s}\), \(\epsilon_0 = 8.854 \times 10^{-12} \text{ F/m}\)[cite: 6]。

\[ r_0 = \frac{4\pi \epsilon_0 \hbar^2}{e^2 m} = \frac{4\pi (8.854 \times 10^{-12})(1.055 \times 10^{-34})^2}{(1.602 \times 10^{-19})^2 (9.109 \times 10^{-31})} \approx 5.29 \times 10^{-11} \text{ m} \]
\[ E_1 = -\frac{\hbar^2}{2m r_0^2} = -\frac{(1.055 \times 10^{-34})^2}{2(9.109 \times 10^{-31})(5.29 \times 10^{-11})^2} \approx -2.18 \times 10^{-18} \text{ J} \approx -13.6 \text{ eV} \]
