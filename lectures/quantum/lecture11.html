01 \(\Theta(\theta)\) の微分方程式と Legende多項式

極角 \(\theta\) に関する微分方程式の変数変換 \(x = \cos\theta\) から Legendre多項式の導出まで。

変数変換\(x = \cos\theta\) による代数方程式への変換 [p.2]

第10講で得られた \(\Theta(\theta)\) に関する微分方程式は以下の通りである[cite: 5]：

\[\left[ \frac{1}{\sin\theta}\frac{d}{d\theta}\left(\sin\theta \frac{d}{d\theta}\right) + \lambda - \frac{m_l^2}{\sin^2\theta} \right] \Theta(\theta) = 0\]

ここで変数変換 \(x = \cos\theta\) （\(\Theta(\theta) = f(x)\)）を行う[cite: 5]。合成関数の微分公式より[cite: 5]：

\[\frac{d x}{d\theta} = -\sin\theta \implies \frac{d}{d\theta} = -\sin\theta \frac{d}{dx}\]
\[\frac{d^2}{d\theta^2} = \frac{d}{d\theta}\left(-\sin\theta \frac{d}{dx}\right) = -\cos\theta \frac{d}{dx} + \sin^2\theta \frac{d^2}{dx^2}\]

これらを整理して展開すると、**Legendreの陪微分方程式**を得る[cite: 5]：

\[\left[ (1 - x^2)\frac{d^2}{dx^2} - 2x\frac{d}{dx} + \lambda - \frac{m_l^2}{1 - x^2} \right] f(x) = 0\]

\(m_l = 0\)Legendre微分方程式と \(\lambda = l(l+1)\) [p.3, 4]

\(m_l = 0\) の場合、方程式は通常の **Legendre（ルジャンドル）の微分方程式** となる[cite: 5]：

\[(1 - x^2)\frac{d^2 f}{dx^2} - 2x \frac{df}{dx} + \lambda f(x) = 0\]

冪級数 \(f(x) = \sum_{n=0}^{\infty} a_n x^n\) を代入して整理すると、漸化式を得る[cite: 5]：

\[a_{n+2} = \frac{n(n+1) - \lambda}{(n+2)(n+1)} a_n\]

大極限 \(n \gg 1\) では \(a_{n+2} \approx a_n\) となり、\(f(x)\) は \(\sum x^{2k} \sim \frac{1}{1-x^2}\) のように振る舞うため、端点 \(x = \pm 1\) （\(\theta = 0, \pi\)）で発散してしまう[cite: 5]。物理的に有限な値にとどまるため、級数は有限の次数 \(n = l\) で打ち切られなければならない[cite: 5]：

\[l(l+1) - \lambda = 0 \implies \lambda = l(l+1) \quad (l = 0, 1, 2, \dots)\]

この打ち切り条件により定義される多項式解が **Legendre多項式 \(P_l(x)\)** であり、Rodrigues（ロドリゲス）の公式で表される[cite: 5]：

\[P_l(x) = \frac{1}{2^l l!} \frac{d^l}{dx^l} (x^2 - 1)^l\]

02 Legendre陪多項式と角運動量の量子化

\(m_l \neq 0\) での端点特異性の分離と、角運動量の大きさおよび \(z\) 成分の量子化条件。

\(m_l \neq 0\)端点特異性の回避と陪多項式 [p.5, 6]

\(m_l \neq 0\)（簡略化のため \(m_l = m\)）のとき、\(x \to \pm 1\) 付近で \(\frac{m^2}{1-x^2}\) の項が強く発散する[cite: 5]。\(x \approx 1\) 付近での挙動を解析すると \(f(x) \sim (1-x)^{\vert{}m\vert{}/2}\)、\(x \approx -1\) では \(f(x) \sim (1+x)^{\vert{}m\vert{}/2}\) と解かれる[cite: 5]。両端での特異性を分離するため、次のように置く[cite: 5]：

\[f(x) = (1 - x^2)^{\vert{}m\vert{}/2} u(x)\]

これを代入すると、特異項が解消された \(u(x)\) に関する方程式が得られる[cite: 5]：

\[(1 - x^2)\frac{d^2 u}{dx^2} - 2x(1 + \vert{}m\vert{})\frac{du}{dx} + \left[ l(l+1) - \vert{}m\vert{}(\vert{}m\vert{}+1) \right] u(x) = 0\]

この方程式は、Legendre微分方程式 \((1-x^2)P_l'' - 2xP_l' + l(l+1)P_l = 0\) を \(x\) で \(\vert{}m\vert{}\) 回微分した式と完全に一致する[cite: 5]（※付録1参照[cite: 5]）。したがって、\(u(x) \propto \frac{d^{\vert{}m\vert{}}}{dx^{\vert{}m\vert{}}} P_l(x)\) と同定され、**Legendreの陪多項式 \(P_l^{\vert{}m\vert{}}(x)\)** が定義される[cite: 5]：

\[P_l^{\vert{}m\vert{}}(x) = (1 - x^2)^{\vert{}m\vert{}/2} \frac{d^{\vert{}m\vert{}}}{dx^{\vert{}m\vert{}}} P_l(x) = \frac{1}{2^l l!} (1 - x^2)^{\vert{}m\vert{}/2} \frac{d^{l+\vert{}m\vert{}}}{dx^{l+\vert{}m\vert{}}} (x^2 - 1)^l\]

量子化角運動量の量子化と幾何学的制限 [p.7]

\((x^2 - 1)^l\) は \(x\) の \(2l\) 次多項式であるため、\(l + \vert{}m\vert{}\) 回微分してゼロにならないためには、微分の回数が \(2l\) を超えてはならない[cite: 5]：

\[l + \vert{}m\vert{} \le 2l \implies \vert{}m\vert{} \le l \iff -l \le m_l \le l\]

これにより、方位角量子数（軌道角運動量量子数）\(l\) と 磁気量子数 \(m_l\) の量子化条件が導かれた[cite: 5]：

\[l = 0, 1, 2, \dots, \qquad m_l = -l, -(l-1), \dots, 0, \dots, (l-1), l\]

固有値方程式としてまとめると[cite: 5]：

\[\text{全角運動量 2 乗: } \hat{L}^2 Y_{l,m_l}(\theta,\phi) = \hbar^2 l(l+1) Y_{l,m_l}(\theta,\phi)\]
\[ \text{\(z\) 成分角運動量: } \hat{L}_z Y_{l,m_l}(\theta,\phi) = \hbar m_l Y_{l,m_l}(\theta,\phi) \]
なぜ \(\vert{}L_z\vert{} < \vert{}\boldsymbol{L}\vert{}\) なのか？（角運動量の不確定性）：
角運動量の大きさは \(\vert{}\boldsymbol{L}\vert{} = \hbar\sqrt{l(l+1)}\) であり、\(z\) 成分の最大値は \((L_z)_{\text{max}} = \hbar l\) である[cite: 5]。常に \(\vert{}\boldsymbol{L}\vert{} > \vert{}L_z\vert{}\) となり、角運動量が完全に \(z\) 軸方向を向くことはできない[cite: 5]。もし \(L_z = \vert{}\boldsymbol{L}\vert{}\) となると \(L_x = L_y = 0\) と確定してしまい、交換関係 \([\hat{L}_x, \hat{L}_y] = i\hbar \hat{L}_z \neq 0\)（不確定性原理）に矛盾するためである[cite: 5]。

03 規格化された球面調和関数 \(Y_{l,m}(\theta, \phi)\)

角度解 \(\Theta(\theta)\Phi(\phi)\) の規格化と、\(l=0,1,2\)（\(s, p, d\) 軌道）の具体形と空間分布。

規格化球面調和関数の統一的表式 [p.8, 9]

Legendre陪多項式の直交性積分 \(\int_{-1}^1 dx P_l^{\vert{}m\vert{}}(x) P_{l'}^{\vert{}m\vert{}}(x) = \delta_{ll'} \frac{2}{2l+1} \frac{(l+\vert{}m\vert{})!}{(l-\vert{}m\vert{})!}\) から規格化定数 \(N_{lm}\) を決定し、方位角解 \(\Phi(\phi) = \frac{1}{\sqrt{2\pi}} e^{im\phi}\) と合成する[cite: 5]。標準的な位相因子（Condon-Shortley位相 \((-1)^m\)）を含めた**球面調和関数 \(Y_{l,m}(\theta, \phi)\)** の一般式は以下の通りである[cite: 5]：

\[Y_{l,m}(\theta,\phi) = (-1)^{(m+\vert{}m\vert{})/2} \sqrt{\frac{(2l+1)(l-\vert{}m\vert{})!}{4\pi(l+\vert{}m\vert{})!}} P_l^{\vert{}m\vert{}}(\cos\theta) e^{im\phi}\]

全立体角にわたる正規直交関係を満たす[cite: 5]：

\[\int_0^{\pi} d\theta \sin\theta \int_0^{2\pi} d\phi \, Y_{l',m'}^*(\theta,\phi) Y_{l,m}(\theta,\phi) = \delta_{ll'} \delta_{mm'}\]

具体形\(l=0,1,2\) の球面調和関数一覧 [p.10, 11]

\(m \ge 0\) に対する公式 \(Y_{l,m} = (-1)^m \sqrt{\frac{(2l+1)(l-m)!}{4\pi(l+m)!}} \frac{1}{2^l l!} (1-x^2)^{m/2} \frac{d^{l+m}}{dx^{l+m}}(x^2-1)^l e^{im\phi}\) （\(x=\cos\theta\)）より計算される具体形[cite: 5]：

① \(l=0\) （\(s\) 軌道：球対称）[cite: 5]

\[Y_{0,0} = \frac{1}{\sqrt{4\pi}}\]

② \(l=1\) （\(p\) 軌道：ダンベル型）[cite: 5]

\[Y_{1,0} = \sqrt{\frac{3}{4\pi}} \cos\theta, \qquad Y_{1,\pm 1} = \mp \sqrt{\frac{3}{8\pi}} \sin\theta e^{\pm i\phi}\]

③ \(l=2\) （\(d\) 軌道：クローバー／\(d_{z^2}\) 型）[cite: 5]

\[Y_{2,0} = \sqrt{\frac{5}{16\pi}} (3\cos^2\theta - 1), \qquad Y_{2,\pm 1} = \mp \sqrt{\frac{15}{8\pi}} \cos\theta \sin\theta e^{\pm i\phi}, \qquad Y_{2,\pm 2} = \sqrt{\frac{15}{32\pi}} \sin^2\theta e^{\pm 2i\phi}\]
