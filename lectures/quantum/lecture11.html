Legendre陪微分方程式、軌道量子数、球面調和関数の体系化

01 \(\Theta(\theta)\) の微分方程式と Legende多項式

極角 \(\theta\) に関する微分方程式の変数変換 \(x = \cos\theta\) から Legendre多項式の導出まで（p.2〜4）。

p.2変数変換 \(x = \cos\theta\)

第10講で得られた \(\Theta(\theta)\) に関する微分方程式[cite: 5]：

\[ \left[ \frac{1}{\sin\theta}\frac{d}{d\theta}\left(\sin\theta \frac{d}{d\theta}\right) + \lambda - \frac{m_l^2}{\sin^2\theta} \right] \Theta(\theta) = 0 \]

\(x = \cos\theta\) と置き、\(\frac{d}{d\theta} = -\sin\theta \frac{d}{dx}\) および \(\frac{d^2}{d\theta^2} = \sin^2\theta \frac{d^2}{dx^2} - \cos\theta \frac{d}{dx}\) を用いて変形すると、**Legendreの陪微分方程式**を得る[cite: 5]：

\[ \left[ (1 - x^2)\frac{d^2}{dx^2} - 2x\frac{d}{dx} + \lambda - \frac{m_l^2}{1 - x^2} \right] f(x) = 0 \]

p.3,4\(m_l = 0\) でのLegendre多項式 \(P_l(x)\)

\(m_l = 0\) のとき、級数解 \(f(x) = \sum a_n x^n\) を代入すると次の漸化式を得る[cite: 5]：

\[ a_{n+2} = \frac{n(n+1) - \lambda}{(n+2)(n+1)} a_n \]

端点 \(x = \pm 1\)（\(\theta = 0, \pi\)）で級数が発散しない（有限項で打ち切られる）ための条件より[cite: 5]：

\[ \lambda = l(l+1) \quad (l = 0, 1, 2, \dots) \]

打ち切られた多項式解が **Legendre多項式 \(P_l(x)\)** （Rodriguesの公式）である[cite: 5]：

\[ P_l(x) = \frac{1}{2^l l!} \frac{d^l}{dx^l} (x^2 - 1)^l \]

02 Legendre陪多項式と角運動量の量子化

\(m_l \neq 0\) での特異性分離と、角運動量量子数 \(l, m_l\) の決定（p.5〜7）。

p.5,6Legendreの陪多項式 \(P_l^{|m|}(x)\)

\(x \to \pm 1\) での強特異性を回避するため、\(f(x) = (1 - x^2)^{|m|/2} u(x)\) と置く[cite: 5]。これを代入して得られる \(u(x)\) の方程式は、Legendre方程式を \(|m|\) 回微分した式と一致する[cite: 5]：

\[ \left[ (1 - x^2)\frac{d^2}{dx^2} - 2x(1 + |m|)\frac{d}{dx} + l(l+1) - |m|(|m|+1) \right] u(x) = 0 \]

これにより **Legendre陪多項式 \(P_l^{|m|}(x)\)** が導かれる[cite: 5]：

\[ P_l^{|m|}(x) = (1 - x^2)^{|m|/2} \frac{d^{|m|}}{dx^{|m|}} P_l(x) = \frac{1}{2^l l!} (1 - x^2)^{|m|/2} \frac{d^{l+|m|}}{dx^{l+|m|}} (x^2 - 1)^l \]

p.7角運動量の量子化と不確定性

\((x^2-1)^l\) は \(2l\) 次式であるため、\(l+|m|\) 回微分してゼロにならない条件より \(|m| \le l\) が必要となる[cite: 5]。量子化された固有値は[cite: 5]：

\[ l = 0, 1, 2, \dots, \qquad m_l = -l, -(l-1), \dots, 0, \dots, (l-1), l \]
\[ \hat{L}^2 Y_{l,m_l} = \hbar^2 l(l+1) Y_{l,m_l}, \qquad \hat{L}_z Y_{l,m_l} = \hbar m_l Y_{l,m_l} \]

03 規格化された球面調和関数 \(Y_{l,m}(\theta, \phi)\)

球面調和関数の規格化表式と \(l=0, 1, 2\)（\(s, p, d\) 軌道）の形（p.8〜11）。

p.8,9球面調和関数と正規直交性

規格化定数および位相因子を含めた **球面調和関数 \(Y_{l,m}(\theta,\phi)\)** の式[cite: 5]：

\[ Y_{l,m}(\theta,\phi) = (-1)^{(m+|m|)/2} \sqrt{\frac{(2l+1)(l-|m|)!}{4\pi(l+|m|)!}} P_l^{|m|}(\cos\theta) e^{im\phi} \]

全立体角での正規直交関係[cite: 5]：

\[ \int_0^{\pi} d\theta \sin\theta \int_0^{2\pi} d\phi \, Y_{l',m'}^*(\theta,\phi) Y_{l,m}(\theta,\phi) = \delta_{ll'} \delta_{mm'} \]

p.10,11\(l=0,1,2\) の球面調和関数一覧

① \(l=0\) （\(s\) 軌道：球対称）[cite: 5]

\[ Y_{0,0} = \frac{1}{\sqrt{4\pi}} \]

② \(l=1\) （\(p\) 軌道）[cite: 5]

\[ Y_{1,0} = \sqrt{\frac{3}{4\pi}} \cos\theta, \qquad Y_{1,\pm 1} = \mp \sqrt{\frac{3}{8\pi}} \sin\theta e^{\pm i\phi} \]

③ \(l=2\) （\(d\) 軌道）[cite: 5]

\[ Y_{2,0} = \sqrt{\frac{5}{16\pi}}(3\cos^2\theta - 1), \quad Y_{2,\pm 1} = \mp \sqrt{\frac{15}{8\pi}}\cos\theta\sin\theta e^{\pm i\phi}, \quad Y_{2,\pm 2} = \sqrt{\frac{15}{32\pi}}\sin^2\theta e^{\pm 2i\phi} \]

04 演習問題10 詳細解説と検算

漸化式によるLegendre多項式の導出と条件 \(P_l(1) = 1\) による定数決定（p.13, 14）。

p.13,14演習問題10：Legendre多項式の具体形と検算

漸化式 \(a_{n+2} = \frac{(n-l)(n+l+1)}{(n+2)(n+1)} a_n\) より各 \(l\) の解を求め、端点条件 \(f(1) = 1\) より定数を決定する[cite: 5]：

① \(l=0\): \(a_2 = 0 \implies f(x) = A\)。\(f(1)=1 \implies A=1 \implies P_0(x) = 1\)[cite: 5]

② \(l=1\): \(a_3 = 0 \implies f(x) = Bx\)。\(f(1)=1 \implies B=1 \implies P_1(x) = x\)[cite: 5]

③ \(l=2\): \(a_2 = -3A, a_4 = 0 \implies f(x) = A(1 - 3x^2)\)。\(f(1) = -2A = 1 \implies A = -1/2 \implies P_2(x) = \frac{1}{2}(3x^2 - 1)\)[cite: 5]

④ \(l=3\): \(a_3 = -\frac{5}{3}B, a_5 = 0 \implies f(x) = B\left(x - \frac{5}{3}x^3\right)\)。\(f(1) = -\frac{2}{3}B = 1 \implies B = -\frac{3}{2} \implies P_3(x) = \frac{1}{2}(5x^3 - 3x)\)[cite: 5]

05 第11講 全付録（1〜3）数学的完全証明

Leibniz則微分、Legendre多項式・陪多項式の規格化積分の完全導出（p.15〜17）。

付録 1Legendre微分方程式の \(m\) 回微分 [p.15]

Leibnizの微分公式 \((uv)^{(m)} = \sum \binom{m}{k} u^{(k)} v^{(m-k)}\) を \((1-x^2)P_l'' - 2xP_l' + l(l+1)P_l = 0\) に適用する[cite: 5]：

\[ (1-x^2) P_l^{(m+2)} - 2x(m+1) P_l^{(m+1)} + [l(l+1) - m(m+1)] P_l^{(m)} = 0 \]

付録 2, 3規格化積分 \(\int_{-1}^1 [P_l(x)]^2 dx = \frac{2}{2l+1}\) の証明 [p.16, 17]

\[ \begin{aligned} \int_{-1}^1 [P_l(x)]^2 dx &= \frac{1}{(2^l l!)^2} \int_{-1}^1 \left[\frac{d^l}{dx^l}(x^2-1)^l\right] \left[\frac{d^l}{dx^l}(x^2-1)^l\right] dx \\ &= \frac{(-1)^l}{(2^l l!)^2} \int_{-1}^1 (x^2-1)^l \frac{d^{2l}}{dx^{2l}}(x^2-1)^l dx = \frac{(2l)!}{(2^l l!)^2} \int_{-1}^1 (1-x^2)^l dx = \frac{2}{2l+1} \end{aligned} \]
