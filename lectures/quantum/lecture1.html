大問1 (a)均一重み \(\hat{u}(k) = \frac{1}{\sqrt{2\pi}}\) とデルタ関数

代入すると \(u(x) = \frac{1}{2\pi} \int_{-\infty}^{\infty} e^{ikx} dk\) となり、デルタ関数のフーリエ表示に合致する[cite: 9]：

\[ u(x) = \delta(x) \]

大問1 (b)帯域制限重み \(\hat{u}(k) = 1 \; (|k| \le 1)\) の計算

積分範囲を \([-1, 1]\) に制限し、オイラーの公式 \(e^{ix} - e^{-ix} = 2i\sin x\) を適用する[cite: 9]：

\[ u(x) = \sqrt{\frac{2}{\pi}} \frac{\sin x}{x} \]

大問2 (a)(b)(c)領域別方程式、解の形、接続条件

領域1 (\(x<0\)): \(u_1 = A_1 e^{ikx} + A_2 e^{-ikx}\)[cite: 9]

領域2 (\(0 \le x \le a\)): \(u_2 = B_1 e^{kx} + B_2 e^{-kx}\)[cite: 9]

領域3 (\(x>a\)): \(u_3 = C e^{ikx}\)[cite: 9]

接続条件を解くことで導かれる係数[cite: 9]：

\[ A_1 = e^{ika} \cosh(ka) C, \qquad A_2 = -i e^{ika} \sinh(ka) C \]
\[ B_1 = \frac{1+i}{2} e^{(ik-k)a} C, \qquad B_2 = \frac{1-i}{2} e^{(ik+k)a} C \]

大問2 (d)透過確率 \(T\) と反射確率 \(R\)

\[ T = \left|\frac{C}{A_1}\right|^2 = \frac{1}{\cosh^2(ka)} = \frac{1}{1 + \sinh^2(ka)} \]
\[ R = \left|\frac{A_2}{A_1}\right|^2 = \tanh^2(ka) = \frac{\sinh^2(ka)}{\cosh^2(ka)} \]

大問3 (f)(g)動径関数 \(\chi(r)\) の両極限解

(f) 遠方極限 \(r \to \infty\): \(\frac{d^2\chi}{dr^2} = \alpha^2 \chi \implies \chi(r) \propto e^{-\alpha r}\) （\(\alpha = \frac{\sqrt{-2m_e E}}{\hbar}\)）[cite: 9]

(g) 原点極限 \(r \to 0\): \(\frac{d^2\chi}{dr^2} - \frac{l(l+1)}{r^2}\chi = 0 \implies \chi(r) \propto r^{l+1}\)[cite: 9]
