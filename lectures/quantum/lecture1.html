[1] 波動関数と重み関数（フーリエ変換）

波数空間における重み関数 \(\hat{u}(k)\) から実空間の波動関数 \(u(x)\) を逆フーリエ変換により求める問題。

(a)全波数帯域の均一な重ね合わせ

重み関数：\(\hat{u}(k) = \frac{1}{\sqrt{2\pi}}\)

\[ u(x) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{\infty} d k \, e^{i k x} \left(\frac{1}{\sqrt{2\pi}}\right) = \frac{1}{2\pi} \int_{-\infty}^{\infty} e^{i k x} d k \]

ディラックのデルタ関数の表現式 \(\delta(x) = \frac{1}{2\pi}\int_{-\infty}^{\infty} e^{ikx} dk\) を適用する。

解： \( u(x) = \delta(x) \)

あらゆる波数が等しい重みで存在する状態は、空間的に完全に局所化したデルタ関数に対応する（位置の不確定性が0）。

(b)有限領域 \(|k| \le 1\) の重ね合わせ

重み関数：\(\hat{u}(k) = 1 \; (|k| \le 1), \quad 0 \; (|k| > 1)\)

\[ \begin{aligned} u(x) &= \frac{1}{\sqrt{2\pi}} \int_{-1}^{1} 1 \cdot e^{i k x} d k = \frac{1}{\sqrt{2\pi}} \left[ \frac{e^{i k x}}{i x} \right]_{-1}^{1} \\ &= \frac{1}{\sqrt{2\pi}} \frac{e^{i x} - e^{-i x}}{i x} = \frac{1}{\sqrt{2\pi}} \frac{2 i \sin x}{i x} \end{aligned} \]
解： \( u(x) = \sqrt{\frac{2}{\pi}} \frac{\sin x}{x} \)

Sinc関数型の波動関数となる。波数幅を制限することで空間的な広がりが生じる（不確定性原理の一例）。

[2] 1次元ポテンシャル障壁の散乱

高さ \(V_0 = 2E\) の障壁に対する電子のトンネル効果と反射・透過係数の導出。

(a)領域ごとのSchrödinger方程式

入射エネルギー \(E\) に対し、各領域のポテンシャルを適用：

\[ \text{領域1 } (x < 0): \quad -\frac{\hbar^2}{2m_e}\frac{d^2 u}{dx^2} = E u(x) \]
\[ \text{領域2 } (0 \le x \le a): \quad -\frac{\hbar^2}{2m_e}\frac{d^2 u}{dx^2} + 2E u(x) = E u(x) \implies -\frac{\hbar^2}{2m_e}\frac{d^2 u}{dx^2} = -E u(x) \]
\[ \text{領域3 } (x > a): \quad -\frac{\hbar^2}{2m_e}\frac{d^2 u}{dx^2} = E u(x) \]

(b)各領域の波動関数の解

\(k = \frac{\sqrt{2m_e E}}{\hbar}\) と置くと、領域2では \(\frac{d^2 u}{dx^2} = k^2 u\) となるため解は指数関数となる。

解：
・領域1 (\(x < 0\)): \(u_1(x) = A_1 e^{ikx} + A_2 e^{-ikx}\)
・領域2 (\(0 \le x \le a\)): \(u_2(x) = B_1 e^{kx} + B_2 e^{-kx}\)
・領域3 (\(x > a\)): \(u_3(x) = C e^{ikx}\)（右進波のみ）

(c)境界条件による係数の決定

\(x=0\) および \(x=a\) における \(u(x)\) と \(u'(x)\) の連続性：

\[ \begin{cases} A_1 + A_2 = B_1 + B_2 & (x=0 \text{ 連続}) \\ ik(A_1 - A_2) = k(B_1 - B_2) \implies i(A_1 - A_2) = B_1 - B_2 & (x=0 \text{ 微分連続}) \\ B_1 e^{ka} + B_2 e^{-ka} = C e^{ika} & (x=a \text{ 連続}) \\ k(B_1 e^{ka} - B_2 e^{-ka}) = ik C e^{ika} \implies B_1 e^{ka} - B_2 e^{-ka} = i C e^{ika} & (x=a \text{ 微分連続}) \end{cases} \]

\(x=a\) の関係より \(B_1, B_2\) を \(C\) で表すと：

\(B_1 = \frac{1+i}{2} C e^{(i-1)ka}\), \quad \(B_2 = \frac{1-i}{2} C e^{(i+1)ka}\)

これを \(x=0\) の式に代入して整理：

解：
\(B_1 = \frac{1+i}{2} C e^{(i-1)ka}\)
\(B_2 = \frac{1-i}{2} C e^{(i+1)ka}\)
\(A_1 = C e^{ika} \left[ \cosh(ka) - i \sinh(ka) \right]\)
\(A_2 = i C e^{ika} \sinh(ka)\)

(d)透過確率 \(T\) と反射確率 \(R\)

\(\left|\cosh(ka) - i \sinh(ka)\right|^2 = \cosh^2(ka) + \sinh^2(ka) = 1 + 2\sinh^2(ka)\)

透過率 \(T\)：
\[ T = \left|\frac{C}{A_1}\right|^2 = \frac{1}{1 + 2\sinh^2(ka)} \]\n 反射率 \(R\)：
\[ R = \left|\frac{A_2}{A_1}\right|^2 = \frac{2\sinh^2(ka)}{1 + 2\sinh^2(ka)} \]
確率の保存： 常に \(T + R = 1\) が成り立つ。古典的にはエネルギー不足（\(E < 2E\)）で100%反射されるが、量子効果によりトンネル透過（\(T > 0\)）が発生する。

[3] 3次元中心力場と水素原子

球面座標系における角度依存性（球面調和関数）と動径方程式の極限挙動。

(a)〜(c)\(\Phi(\phi)\) の解・周期条件・規格化

(a) 一般解：
\(\frac{d\Phi}{d\phi} = i m \Phi \implies \Phi(\phi) = C e^{im\phi}\)

(b) 周期境界条件：
\(\Phi(\phi + 2\pi) = \Phi(\phi) \implies e^{i m 2\pi} = 1\)

制約： \(m\) は整数 (\(m = 0, \pm 1, \pm 2, \dots\))

(c) 規格化：
\(\int_0^{2\pi} |\Phi(\phi)|^2 d\phi = 1 \implies |C|^2 \int_0^{2\pi} d\phi = 2\pi |C|^2 = 1\)

係数： \(C = \frac{1}{\sqrt{2\pi}}\)

(d)球面調和関数 \(Y_{2,0}(\theta, \phi)\) の導出

\((l, m) = (2, 0)\) を公式に代入 (\(x = \cos\theta\)):

\[ Y_{2,0} = N_{2,0} (1-x^2)^0 \frac{d^2}{dx^2}(x^2 - 1)^2 e^{0} \]

\((x^2-1)^2 = x^4 - 2x^2 + 1\) を2階微分：\(\frac{d^2}{dx^2}(x^4 - 2x^2 + 1) = 12x^2 - 4 = 4(3x^2 - 1)\)

角度部分の規格化定数 \(N_{2,0} = \sqrt{\frac{5}{16\pi}} \cdot \frac{1}{8}\)（展開調整後）：

解： \( Y_{2,0}(\theta) = \sqrt{\frac{5}{16\pi}} (3\cos^2\theta - 1) \)

(e)\(|Y_{2,0}|\) の極座標プロット概形

\(|3\cos^2\theta - 1|\) の形状評価：

・\(\theta = 0, \pi\)（z軸方向）：極大値 \(|3(1) - 1| = 2\)
・\(\theta = \pi/2\)（xy平面上）：極小値 \(|3(0) - 1| = 1\)
・\(3\cos^2\theta - 1 = 0 \implies \cos\theta = \pm 1/\sqrt{3}\) (\(\approx 54.7^\circ\)) でゼロ点。

選択肢： (ウ) （z軸方向に大きなローブを持ち、赤道方向にも小さな膨らみを持つ $d_{z^2}$ 型パターン）

(f)動径関数の遠方極限 \(r \to \infty\)

\(r \to \infty\) で Coulomb 項 \(\propto 1/r\) および遠心力ポテンシャル \(\propto 1/r^2\) は無視できる。

\[ -\frac{\hbar^2}{2m_e} \frac{d^2\chi}{dr^2} = E \chi(r) \implies \frac{d^2\chi}{dr^2} = -\frac{2m_e E}{\hbar^2} \chi(r) \]

\(E < 0\)（束縛状態）より \(\beta = \frac{\sqrt{-2m_e E}}{\hbar} > 0\) と置くと、\(\frac{d^2\chi}{dr^2} = \beta^2 \chi\)

一般解は \(\chi(r) = C_1 e^{-\beta r} + C_2 e^{\beta r}\)。\(r \to \infty\) での発散を防ぐ束縛条件 (\(\chi \to 0\)) より \(C_2 = 0\)。

解： \( \chi(r) \propto e^{-\beta r} \quad \left( \text{但し } \beta = \frac{\sqrt{-2m_e E}}{\hbar} \right) \)

(g)動径関数の原点極限 \(r \to 0\)

\(r \to 0\) では、最も強く発散する遠心力項 \(\frac{\hbar^2 l(l+1)}{2m_e r^2}\) が支配的となる。

\[ -\frac{\hbar^2}{2m_e} \frac{d^2\chi}{dr^2} + \frac{\hbar^2 l(l+1)}{2m_e r^2} \chi(r) = 0 \implies r^2 \frac{d^2\chi}{dr^2} - l(l+1)\chi = 0 \]

試行解 \(\chi(r) = r^s\) を代入すると：\(s(s-1) - l(l+1) = 0 \implies s = l+1, \, -l\)

原点での波動関数の規格化可能性（\(r \to 0\) で \(\chi(0) = 0\)）から、正の冪指数を選択：

解： \( \chi(r) \propto r^{l+1} \)
